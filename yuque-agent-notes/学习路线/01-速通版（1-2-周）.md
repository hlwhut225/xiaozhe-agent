# 速通版（1-2 周）

Agent 面试学习路线：速通版（1-2 周）

> 适用场景：面试临近、时间紧迫、需要快速建立可面试的回答框架。 复习策略：只看高频核心题，优先覆盖最常考点。

## 速通目标

速通版不是把所有题全部背完，而是在最短时间内建立 5 类面试能力：

1.  能讲清楚 Agent、LLM、Prompt、RAG、Tool、Harness 的关系。

1.  能画出一个生产级 Agent 系统的核心架构。

1.  能解释 RAG、工具调用、状态管理、评估、安全的关键工程取舍。

1.  能回答常见场景题：智能客服、代码生成、报告撰写、多 Agent、稳定性、成本、延迟。

## 必刷题型清单

### Agent 架构类

-   Agent 的核心组件有哪些？

-   LLM 与 Agent 有什么区别？

-   一个完整的 Agent 架构包含哪些部分？

-   Agent 的规划、任务分解、决策机制是什么？

-   什么是 Execution Loop？

-   Agent 如何处理重试和错误恢复？

-   Agent 的记忆系统如何设计？

-   Agent 如何管理状态？

-   Agent Harness 解决什么问题？

### RAG 类

-   RAG 的工作流程是什么？

-   Chunk Size 如何选择？

-   向量数据库如何选择？

-   向量相似度搜索如何实现？

-   如何优化召回率和精确率？

-   Rerank 的作用是什么？

-   RAG 如何减少幻觉？

-   RAG 和微调如何选择？

### 工具调用类

-   Tool Use 和 Function Calling 的区别是什么？

-   Agent 如何选择工具？

-   Tool Schema 如何设计？

-   工具调用失败后如何处理？

-   如何验证工具调用结果可靠性？

-   如何控制工具权限？

-   MCP 是什么？

### 系统设计类

-   如何设计企业级 Agent 系统？

-   如何设计智能客服 Agent？

-   如何设计代码生成 Agent？

-   如何支持高并发？

-   如何降低延迟？

-   如何控制 Token 成本？

-   如何设计缓存、日志、Fallback、优雅降级？

### 评估与安全类

-   如何评估 Agent 质量？

-   如何设计 Benchmark？

-   如何评估 RAG？

-   如何检测幻觉？
